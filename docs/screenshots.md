# Application screenshots

The four README images are browser captures of the working Air Freight Signals application, recorded 3 November 2026 at 1440 × 1200 in Chromium. They show the bundled genuine 2024–2025 data with default full-year filters: Market Overview, Cargo Corridor Explorer (top 25 routes), Research Findings and Shenzhen → Anchorage under Case Studies. The explorer capture uses the World view and Freight volume encoding, with regional camera controls and locally bundled land and coastlines. No interface or observations were synthesized. The images contain no browser chrome or personal filesystem paths.

The application uses the committed system-font theme. To reproduce, install the requirements, run `python -m streamlit run app.py --browser.gatherUsageStats false`, open localhost:8501, select each workspace and wait for tables and charts to settle. Browser automation is optional and is not a runtime dependency.
